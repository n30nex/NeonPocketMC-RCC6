# NeonPocket Ultimate Companion RCC6 v2.3.0 RC3

Ultimate 2.3 RC3 is an experimental RCC6-L62/SX1262 + 220×128 NV3001B prerelease. It retains the human-first TFT and WebUI experience from RC2 and adds a separate native-USB companion image.

## Choose exactly one image

- BLE: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.3-BLE-app.bin`
- native USB: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.3-USB-app.bin`
- Web: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.3-Web-app.bin`
- signed Web OTA: `NeonPocketMC-RCC6-Ultimate-Web-v2.3.0-rc.3.npu`

Normal flashing writes the selected app-only binary at `0x10000`. Use the separately named merged recovery image at `0x0` only for bootloader/partition recovery. Neither path reaches SPIFFS; do not erase the whole chip.

Native USB carries the standard binary MeshCore companion protocol and is not the text configuration CLI. BLE, USB, and Wi-Fi are compile-time alternatives and never run together.

## Source baseline

This release uses official MeshCore 1.17.0 plus the post-release SX126x boosted-RX-gain persistence fix already carried by the project.

## Network boundary

The Web image keeps TCP/5000 enabled. It exposes the complete MeshCore companion/admin protocol to every trusted LAN client, so use Web mode only on a private network.
