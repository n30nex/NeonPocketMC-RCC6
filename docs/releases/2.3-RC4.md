# NeonPocket Ultimate Companion RCC6 v2.3.0 RC4

Ultimate 2.3 RC4 is an experimental RCC6-L62/SX1262 + 220×128 NV3001B prerelease. It retains the BLE, native-USB, and authenticated Web modes from RC3.

## Choose exactly one image

- BLE: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.4-BLE-app.bin`
- native USB: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.4-USB-app.bin`
- Web: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.4-Web-app.bin`
- signed Web OTA: `NeonPocketMC-RCC6-Ultimate-Web-v2.3.0-rc.4.npu`

Normal flashing writes the selected app-only binary at `0x10000`. Use the matching recovery image at `0x0` only for bootloader/partition recovery. Neither path reaches SPIFFS; do not erase the whole chip.

## Location-advert correction

The Web location action now confirms whether the saved browser coordinates will be included in MeshCore adverts. The API saves the existing MeshCore advert-location policy with the coordinates. Older clients that omit the new choice keep the node's prior policy.

BLE and native USB behavior is unchanged and regression-built. BLE, USB, and Wi-Fi remain compile-time alternatives.

## Network boundary

The Web image keeps TCP/5000 enabled. It exposes the complete MeshCore companion/admin protocol to every trusted LAN client, so use Web mode only on a private network.
