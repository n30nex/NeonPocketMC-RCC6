# NeonPocket Ultimate Companion RCC6 v2.1.0 RC1

Ultimate 2.1 is an experimental RCC6-L62/SX1262 + 220×128 NV3001B candidate. It keeps v1.2 RC2 and Ultimate 2.0 RC1 available and must not be flashed to RC32, RC52, or another RadioCore layout.

The release gallery is refreshed from CRC-checked frames exported by the connected RCC6 and includes the Home, Inbox, Network, Radio, Tools, Power, target-picker, and quick-phrase views.

## Choose exactly one image

- BLE: `NeonPocketMC-RCC6-Ultimate-v2.1.0-rc.1-BLE-app.bin`
- Web: `NeonPocketMC-RCC6-Ultimate-v2.1.0-rc.1-Web-app.bin`
- signed Web OTA: `NeonPocketMC-RCC6-Ultimate-Web-v2.1.0-rc.1.npu`

Normal USB flashing writes the app-only binary at `0x10000`. Use a separately named merged recovery image at `0x0` only for bootloader/partition recovery. Neither path reaches SPIFFS; do not erase the whole chip.

## What 2.1 adds

- The latest message composed on the TFT has an exact 64-bit packet-hash state: Queued, On Air, Transmitted, ACKed with round-trip time, No ACK, Unconfirmed, or Failed. Phone/app traffic cannot consume this receipt; an unobserved queue outcome becomes Unconfirmed rather than inventing success.
- Composer state keeps one pinned target and one crash-safe 140-byte draft. `REPLY LATEST` and `RESUME DRAFT` are first-class Tools actions. Quick phrases may contain `{name}`, `{battery}`, or `{location}`.
- The renderer targets 66 ms frames, then automatically backs off to 100, 125, or 150 ms under measured display, queue, heap, or Battery-profile pressure.
- Balanced, Field, and Battery profiles use 60-second, 5-minute, and 30-second TFT timeouts. After at least ten minutes of samples the UI reports battery trend and, while discharging, estimated time to 3.45 V. A -300 to +300 mV calibration offset is available in the authenticated WebUI.
- Message and Network views decode MeshCore's packed path field before displaying hops. Three-byte hash mode with a direct/zero-hop path now reads `0 hops`, never the encoded value `128`.

Power-page double press cycles the power profile. Long hold still arms shutdown; a second hold within eight seconds powers off after release.

BLE users can set the same options from USB CLI Rescue:

```text
np power balanced
np power field
np power battery
np battery offset -25
```

Compare the displayed battery voltage with a multimeter, then enter only the signed difference in millivolts. Valid calibration offsets are -300 through +300 mV.

## Composer

1. Open Tools and choose Reply Latest, Compose, or Resume Draft.
2. Select a recent direct contact or configured channel. Pinning places that target first next time.
3. Select one of eight editable phrases or Custom Keyboard.
4. Single press advances; double press selects.
5. Page through the complete preview, then double-press to send.

Keyboard cadence remains selectable at 450, 650, 900, or 1,200 ms. Case, space, punctuation, backspace, cancel, and explicit send are preserved.

## Web settings and telemetry

The authenticated Ultimate status/settings APIs additionally expose delivery state, battery trend/runtime estimate, calibrated voltage, active power profile, adaptive frame interval, display timeout, and display-transfer EMA. The existing history, export, location, and signed OTA endpoints are unchanged.

TCP/5000 remains always enabled in Web mode and carries the unrestricted MeshCore companion/admin protocol. Any trusted-LAN client can use it; HTTP authentication does not protect it.
