# NeonPocket Ultimate Companion RCC6 v2.0.0 RC1

Ultimate v2 is an experimental RCC6-L62/SX1262 + 220×128 NV3001B release. It does not replace v1.2 RC2 and must not be flashed to RC32, RC52, or another RadioCore layout.

The release gallery contains direct, CRC-checked frames captured from the connected RCC6 framebuffer: [Home, Inbox, Network, Radio, Tools, and Power](../../README.md#ultimate-on-device-gallery).

## Choose exactly one image

- BLE: `NeonPocketMC-RCC6-Ultimate-v2.0.0-rc.1-BLE-app.bin`
- Web: `NeonPocketMC-RCC6-Ultimate-v2.0.0-rc.1-Web-app.bin`
- signed Web OTA: `NeonPocketMC-RCC6-Ultimate-Web-v2.0.0-rc.1.npu`

Normal USB flashing writes the app-only binary at `0x10000`. The separately named merged recovery images write at `0x0` only when bootloader/partition recovery is required. Neither release image reaches the SPIFFS data partition; do not erase the whole chip.

## Controls

| Gesture | Result |
| --- | --- |
| First gesture with TFT off | Wake only |
| Single press | Next area, item, message page, or keyboard choice |
| Double press | Open, select, or confirm the displayed action |
| Long hold | Show Power confirmation |
| Second hold within eight seconds | Enter system-off after release |

The six top-level areas are Home, Inbox, Network, Radio, Tools, and Power. Tools contains Compose, Advert, transport toggle, history retention/clear, notification privacy, and build information.

## One-switch composer

1. Open Tools and select Compose.
2. Select a recently active direct contact or configured channel.
3. Select one of eight editable phrases or Custom Keyboard.
4. In the keyboard, single press advances and double press selects.
5. Custom text is limited to 140 UTF-8 bytes and always requires an explicit final Send confirmation.

Keyboard cadence can be 450, 650, 900, or 1,200 ms; 650 ms is the default. Case, space, punctuation, backspace, cancel, and send are explicit choices.

## On-device history

The separate `/np/` journal uses fixed 256-byte records with CRC and alternating metadata. Retention is Off, 128, 512, or 2,048 records; 512 is the default. Lowering capacity retains the newest records. Off stops future writes without erasing old data. Clear is a separate confirmed operation.

History is plaintext. Use Private notifications only to hide bodies on a locked TFT; it is not storage encryption.

CLI Rescue commands:

```text
np status
np history export
np history capacity off
np history capacity 128
np history capacity 512
np history capacity 2048
np history clear CONFIRM
np private on
np private off
np cadence 450
np cadence 650
np cadence 900
np cadence 1200
np phrase 1 On my way
```

## Ultimate Web APIs

The Web image exposes authenticated endpoints:

```text
GET    /api/ultimate/status
GET    /api/ultimate/history?before=<sequence>&limit=<1..50>
GET    /api/ultimate/export
DELETE /api/ultimate/history          X-NP-Confirm: clear
GET    /api/ultimate/settings
PUT    /api/ultimate/settings
PUT    /api/ultimate/location
POST   /api/ultimate/ota
```

Browser location is requested only after a user gesture and requires confirmation of coordinates and accuracy. HTTP on a joined LAN uses Basic username `meshcore` and the device password shown on the TFT.

TCP/5000 remains always enabled for compatibility and carries the unrestricted MeshCore companion/admin protocol. Any trusted-LAN client can use it; HTTP authentication does not protect it.

## Signed Web OTA

The fixed `.npu` header contains target, mode, release version, Git SHA, application length, SHA-256, and Ed25519 signature. The Web firmware verifies every field before opening the inactive OTA slot. Corrupted, unsigned, BLE-mode, or wrong-target packages are rejected. Only the application payload is written.

Automatic rollback is not guaranteed by the existing bootloader. Retain physical USB access and release recovery files.
