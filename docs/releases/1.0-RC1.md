# RadioCore²-RCC6 1.0 RC1

First public release candidate of the MeshCore Companion Bluetooth firmware for the Heltec RadioCore RCC6 and its native 220×128 NV3001B TFT.

## Highlights

- Neon Pocket phone-style dashboard, cards, icons, status chrome, Quick Menu, transitions, and color notifications.
- Native 220×128 RGB565 framebuffer with hashed 8-row delta flushing.
- Stable RCC6 DIO build and settings-preserving app-only update path.
- BLE queue hardening for companion synchronization bursts.
- Physical validation of display, USB stability, BLE advertising, secure PIN authentication, companion node loading, disconnect/re-advertise, reconnect, and battery-powered operation.

## Assets

- `RadioCore2-RCC6-1.0-RC1-app.bin` — recommended app-only update at `0x10000`; preserves MeshCore settings.
- `RadioCore2-RCC6-1.0-RC1-full-recovery-preserves-meshcore-settings.bin` — merged recovery image at `0x0`; resets NVS/BLE bonds while preserving MeshCore identity and settings in SPIFFS.
- `RadioCore2-RCC6-1.0-RC1-third-party-licenses.zip` — third-party license texts and exact source/relinking pointers.
- `SHA256SUMS.txt` — SHA-256 integrity manifest.

## Release-candidate limits

LoRa end-to-end receipts, the complete button matrix, every notification-failure path, and measured battery runtime remain to be qualified before final 1.0.

See the repository README for flashing commands, controls, validation evidence, and safety notes.
