# NeonPocketMC-RCC6 1.2 RC1

Experimental RCC6 companion release based on MeshCore 1.17.0.

## Included files

- `NeonPocketMC-RCC6-1.2-RC1-BLE-app.bin` — normal BLE install at `0x10000`.
- `NeonPocketMC-RCC6-1.2-RC1-BLE-full-recovery-preserves-meshcore-settings.bin` — BLE bootloader/partition recovery at `0x0`.
- `NeonPocketMC-RCC6-1.2-RC1-WebAP-app.bin` — normal Web/AP install at `0x10000`.
- `NeonPocketMC-RCC6-1.2-RC1-WebAP-full-recovery-preserves-meshcore-settings.bin` — Web/AP bootloader/partition recovery at `0x0`.
- `SHA256SUMS` and the exact source/license bundle.

Do not erase the whole flash. The merged images stop before the SPIFFS data partition, preserving MeshCore identity, contacts, channels, and preferences while resetting NVS-backed BLE/Wi-Fi state.

## Changes since 1.1 RC1

- Animated NeonPocketMC startup mark and progress sequence.
- Cached Diagnostics page with uptime, packet, radio, battery, and heap data.
- Six-choice auto-scanning Quick Reply page for the latest valid direct or channel target.
- Canonical repository and WebUI branding.
- Removed the inherited upstream Pages workflow.

## Reduced hardware smoke

The exact RCC6 application image was written and read-back verified on the qualification unit without erasing SPIFFS. It booted with the 56,320-byte display framebuffer and passed the 16 KB companion memory gate. This remains a prerelease; battery ADC calibration and longer endurance testing are deferred.
