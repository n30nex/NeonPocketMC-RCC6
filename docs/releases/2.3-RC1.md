# NeonPocket Ultimate Companion RCC6 v2.3.0 RC1

Ultimate 2.3 is an experimental RCC6-L62/SX1262 + 220×128 NV3001B prerelease. It keeps the stable v1 line and every earlier Ultimate release available.

## Choose exactly one image

- BLE: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.1-BLE-app.bin`
- Web: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.1-Web-app.bin`
- signed Web OTA: `NeonPocketMC-RCC6-Ultimate-Web-v2.3.0-rc.1.npu`

Normal USB flashing writes the app-only binary at `0x10000`. Use the separately named merged recovery image at `0x0` only for bootloader/partition recovery. Neither path reaches SPIFFS; do not erase the whole chip.

## What changed

- A cleaner Overview built around traffic, delivery, storage, battery, and connection health.
- Hourly packet bars, signal distribution, and nearby-radio freshness summaries.
- A Nearby view that uses advertised coordinates when they exist and otherwise shows honest stored-route hop and recency evidence—never invented geography or stale RSSI/SNR.
- Plain human labels throughout the browser UI, with the same responsive layout on desktop and phone.
- The existing on-device Ultimate Home, Inbox, Network, Radio, Tools, Power, journal, composer, signed OTA, and one-button behavior remain intact.

The Web image never runs alongside BLE. TCP/5000 remains enabled and exposes the complete MeshCore companion/admin protocol to every trusted LAN client. Use it only on a private network.

## Source baseline

This release uses official MeshCore 1.17.0 plus the post-release SX126x boosted-RX-gain persistence fix already carried by the project. No official upstream 1.17.1 tag exists at release preparation time.
