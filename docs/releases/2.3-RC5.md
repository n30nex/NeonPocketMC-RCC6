# NeonPocket Ultimate Companion RCC6 v2.3.0 RC5

Ultimate 2.3 RC5 is an experimental RCC6-L62/SX1262 + 220×128 NV3001B safety update. It retains the separate BLE, native-USB, and authenticated Web modes from RC4.

## Choose exactly one image

- BLE: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.5-BLE-app.bin`
- native USB: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.5-USB-app.bin`
- Web: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.5-Web-app.bin`
- signed Web OTA: `NeonPocketMC-RCC6-Ultimate-Web-v2.3.0-rc.5.npu`

Normal flashing writes the selected app-only binary at `0x10000`. Use the matching recovery image at `0x0` only for bootloader/partition recovery. Neither path reaches SPIFFS; do not erase the whole chip.

## Battery-reading correction

RCC6 ADC samples above the plausible 4.50 V ceiling for a single-cell battery are now treated as unavailable. TFT and Web surfaces display an unknown state instead of an impossible voltage, calibrated readings receive the same final check, and stale low-battery warnings are cleared.

BLE, native USB, and Wi-Fi remain compile-time alternatives.

## Network boundary

The Web image keeps TCP/5000 enabled. It exposes the complete MeshCore companion/admin protocol to every trusted LAN client, so use Web mode only on a private network.
