# NeonPocket Ultimate Companion RCC6 v2.3.0 RC2

Ultimate 2.3 RC2 is an experimental RCC6-L62/SX1262 + 220x128 NV3001B prerelease. It contains the same human-first WebUI, analytics, nearby-node map, and standalone TFT experience as RC1, with the on-device About label corrected to the actual firmware baseline.

## Choose exactly one image

- BLE: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.2-BLE-app.bin`
- Web: `NeonPocketMC-RCC6-Ultimate-v2.3.0-rc.2-Web-app.bin`
- signed Web OTA: `NeonPocketMC-RCC6-Ultimate-Web-v2.3.0-rc.2.npu`

Normal USB flashing writes the app-only binary at `0x10000`. Use the separately named merged recovery image at `0x0` only for bootloader/partition recovery. Neither path reaches SPIFFS; do not erase the whole chip.

## Source baseline

This release uses official MeshCore 1.17.0 plus the post-release SX126x boosted-RX-gain persistence fix already carried by the project. No official upstream MeshCore 1.17.1 tag exists at release preparation time.

## RC2 correction

RC1's Tools/About alert incorrectly displayed `Ultimate 2.1 / MeshCore 1.17.1`. RC2 displays `Ultimate 2.3 RC2 / MC 1.17.0+RX`, matching the embedded version metadata and documented source baseline. Firmware behavior is otherwise unchanged.

The Web image never runs alongside BLE. TCP/5000 remains enabled and exposes the complete MeshCore companion/admin protocol to every trusted LAN client. Use it only on a private network.
